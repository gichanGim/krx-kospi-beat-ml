# krx-kospi-beat-ml

가천대학교 컴퓨터공학과 2026-2 **기계학습프로그래밍** 개인 프로젝트.

**질문**: 2024년 말 시점의 재무지표(PER, PBR, 배당수익률, EPS, BPS, 시가총액, 거래대금, 시장, 업종)만 보고,
그 종목이 **2025년 한 해 동안 코스피 지수보다 더 올랐는가**를 맞힐 수 있는가? (이진 분류)

## 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 한국거래소 정보데이터시스템 https://data.krx.co.kr (pykrx로 수집, `src/collect_data.py`) |
| 기준일 | 2024-12-30 (2024년 마지막 거래일) 지표 → 2025-12-30 까지 1년 수익률 |
| 행 | 코스피 + 코스닥 2,694 종목 |
| 열 | BPS, PER, PBR, EPS, DIV, DPS, 시가총액, 거래대금, 상장주식수, 종목명, 수익률_2025, 시장, 업종명, 코스피수익률_2025, delisted, target |
| 레이블 | `target` = 1 if 종목 1년 수익률 > 코스피 지수 1년 수익률(+75.63%) else 0 |
| 파일 | `data/stock_2024.csv` |

코스피가 2025년에 크게 올라 **지수를 이긴 종목은 전체의 12.2%** 뿐이다. 아무것도 하지 않고 전부 0이라 해도 정확도 0.878이 나오는
불균형 데이터이므로, 정확도가 아니라 혼동행렬 네 칸과 클래스별 정밀도·재현율로 읽는다.

## 구조

```
data/        stock_2024.csv (수집 결과)
src/         collect_data.py (수집 코드, KRX 로그인 필요)
notebooks/   학번_이름_프로젝트.ipynb (코랩, 위에서부터 끝까지 실행됨)
docs/        프로젝트_실행계획.md
```

## 방법 (수업 범위 안에서)

1. 살펴보기 → `stratify=y`로 나누기 → 손보기(빈칸·튀는 값·글자→숫자·크기 맞추기, 훈련 데이터로만 fit) → 검산
2. 기준선(다수 클래스) / 로지스틱 회귀(표준화) / 랜덤포레스트(원본) 비교, 교차검증 평균±표준편차
3. 결과 읽기: 클래스별 개수와 혼동행렬 → 어느 실수가 더 비싼가 → 맞는 지표 → 임계값 옮기기 → `classification_report`
